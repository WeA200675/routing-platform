# G6.20 — Local Open-Source LLM Runtime

## Goal

Connect the G6.19 Social AI generation boundary to a reproducible, local-only
open-source LLM runtime without giving generated text authority over navigation.

## Frozen base

- base/main: `c00efe75ba3c6cef7c00c46915706d7dedd4ed02`
- branch: `g6.20/local-open-source-llm`

## Architecture

`Navigation facts -> safety context -> bounded memory recall -> social policy ->
prompt -> local LLM -> response enforcement -> presentation`

The LLM is presentation-only. Route geometry, maneuver truth, positioning,
progress safety gates, permissions, emergency behavior and critical guidance
remain deterministic inputs outside the model.

## Implementation block

1. Reproducible local runtime adapter behind `LocalSocialAiTextGenerationBackend`.
2. Runtime lifecycle with explicit load/unload and one active model.
3. Model artifact SHA-256 verification before load.
4. Runtime/model SPDX metadata and immutable revisions.
5. Bounded context/output tokens and memory entries.
6. Streaming generation contract with cancellation.
7. RAM/storage envelope and fail-closed resource admission.
8. No network permission or implicit cloud fallback for inference.
9. Post-generation enforcement for critical/navigation contexts.
10. Deterministic fallback remains available when no model is loaded.
11. Android unit/instrumentation coverage.
12. CI compiles the instrumentation APK on every relevant branch/PR.
13. SBOM/license/provenance documentation.
14. Physical Pixel 10 Pro latency/memory/offline gate before merge.

## Open-source gate

No model or runtime binary is approved merely by being named as a candidate.
A distributable artifact must have separately reviewed runtime and model
licenses, immutable source/revision provenance, and a verified SHA-256.

## Device gate

The physical gate is deferred until implementation and CI are green.
