# Social AI Safety Contract

G6.19 separates social expression from navigation authority.

## Authority boundary

Social AI may influence wording, presentation, conversational initiative and learned user preferences. It has no API for mutating route geometry, route progress, positioning integrity, permissions or navigation safety gates.

## Context rules

Conversation may use bounded humor, warmth, charm and playfulness. Adult flirt is available only after explicit adult opt-in.

Navigation status always suppresses flirt and substantially reduces nonessential social expression.

Critical guidance suppresses humor, charm, playfulness, proactivity and flirt. It raises directness and preserves warmth without weakening the instruction.

## Generation rule

Optional text generation receives an already safety-filtered SocialAiResponsePlan. A model is not the policy authority. Generated text must never be used as route truth or as an input that bypasses navigation safety gates.

## Failure rule

No local generator means no generated response. There is no implicit cloud fallback. The deterministic social planner remains available independently.
