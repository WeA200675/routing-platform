# G6.20 Runtime Provenance and Distribution Gate

G6.20 defines the integration boundary but does not vendor a model or native
runtime binary by default.

A distributable local LLM package is admitted only when all of the following
are recorded together:

- runtime component id, immutable upstream revision, SPDX license and HTTPS source
- model id, immutable revision, separately reviewed SPDX license and HTTPS source
- exact model SHA-256
- GGUF format and quantization
- expected artifact bytes and minimum RAM envelope
- reproducible native build instructions for the selected runtime
- Android ABI list and toolchain versions
- SBOM entry for runtime and model
- offline test proving inference works with networking unavailable
- physical-device latency and memory measurements

The admission code rejects floating main/master revisions and licenses outside
the reviewed permissive set. Candidate names are not approvals.

## Authority boundary

The native engine receives a verified local file path and bounded prompt. It
has no routing mutation interface and no cloud fallback interface. Generated
text passes through the deterministic G6.19/G6.20 social and critical-guidance
enforcement layer before presentation.
